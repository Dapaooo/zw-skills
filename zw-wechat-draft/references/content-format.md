# content.json 格式与来源标注规范

`content.json` 是 zw-wechat-draft 技能的唯一内容输入。AI 先把文章提炼成这个结构，再由渲染器产出公众号图文。

## 顶层字段

| 字段 | 必填 | 说明 |
|------|------|------|
| title | 是 | 文章标题（会进入草稿箱标题 + 封面）。**建议 ≤ 12 字**，保证横版封面字号够大、1:1 正方形也协调；过长会触发渲染警告、横版字号偏小 |
| subtitle | 否 | 副标题，**用于标注信息来源/栏目**，显示在封面和正文开头 |
| author | 否 | 整理者/作者名，显示在封面右下角 |
| digest | 否 | 摘要；留空则公众号自动抓正文前 54 字 |
| content_type | 否 | 自动选色调：`思辨/哲学` / `技术/工程` / `文学/叙事` / `科学/研究` / `商业/管理` |
| source | 否 | 来源信息，备索引用 |
| palette | 否 | 显式覆盖色调；不填则按 content_type 取预设 |
| blocks | 是 | 内容块数组，见下 |

## block 类型

| type | 字段 | 渲染效果 |
|------|------|----------|
| intro | text | 开篇段落。⚠️ text 内的 `\n\n` **不拆段**（渲染器原样输出，浏览器折叠成空格），需要分段必须拆成多个独立 intro 块 |
| section | title, body | 章节标题 + 正文（body 用 `\n\n` 分段） |
| highlight | text | 金句，左边带强调色竖线 |
| quote | text | 引用块（区别于 highlight）：强调色文字 + 左边线，置于章节顶部或叙事流中 |
| divider | - | 分割线 |
| list | items | 无序列表 |
| item | label, body | 带标签的条目 |
| subtitle | text | 小标题/眉题 |
| footer | text | 结尾说明文字（**用于完整来源声明**） |
| endmark | text | 结束符号，默认 `∎` |

## 金句/引用位置规则（关键，必须对齐长图）

**金句（highlight）与引用（quote）必须保留它们在原文叙事流中的精确位置**——它出现在哪一段之后，就紧跟在那一段之后渲染。严禁把同一章节内的金句/引用全部堆到章节正文末尾（这是最常见的错位）。

长图（zw-card 长图模具）的金句/引用是自由穿插在段落之间的；公众号版必须做到**逐处一致**。

**实现方式：章节用「只写标题的 section + 拆段穿插」表达，而不是把整节正文塞进一个 body。**

- `section` 允许只写 `title`（省略 `body`），仅渲染章节标题 `<h2>`；
- 该章节的正文拆成多个 `intro` 块、金句用 `highlight` 块、引用用 `quote` 块，按叙事顺序与 `intro` 交替排列。

示例（章节内金句穿插在段1与段2之间）：

```json
{ "type": "section", "title": "四、人类文明的进化，靠允许人干蠢事" },
{ "type": "intro", "text": "最大机会：AI 极大赋能个人……每个人背后站着整个文明。" },
{ "type": "highlight", "text": "每个人具有了文明级的认知能力。" },
{ "type": "intro", "text": "但今天的平台是数字封建主义……平台就不足为惧。" },
{ "type": "highlight", "text": "我们就是数字平台里的奴隶。" },
{ "type": "intro", "text": "反对集中精英主义……要求它证明自己错了。" }
```

> 自检：把 blocks 顺序和长图 BODY_HTML 里 `.highlight` / `blockquote` / 段落的出现顺序逐条比对，应一一对应。若某章节的金句全挤在末尾而长图里是穿插的，即为未对齐，需拆段重排。


## 来源标注规范

每篇推送在 `subtitle` 显式标注信息来源，尊重原作者著作权。

1. **`subtitle`**（必做）：来源 + 日期，显示在封面和正文开头
   - 例：`易论AI 深度对话 · 2026.07.09` 或 `摘自《拐点》万维钢 · 2024`
2. **文章末端 `footer` 块**：**默认不再输出**（用户偏好，2026-08-15：去掉文章末端内容来源部分）
   - 渲染器仅在 content.json 显式包含 `footer` 块时才渲染；**规范默认不写**。
   - 若个别文章确需文末来源声明，仍可显式添加（格式见下方「footer 参考（可选）」）。

### footer 参考（可选，默认不输出）

```
内容来源：易论AI《王煜全：2029 年，AI 赛道泡沫破裂》深度访谈（2026.07.09）。
本文由张伟提炼核心论点与金句、按公众号排版规范整理；访谈原文著作权归易论AI 及受访者王煜全所有，整理版仅供个人公众号存档与分享。
```

## 提炼标准（篇幅自检）

- 长文/访谈：提炼骨架 + 金句 + 关键引述，压缩正文；**篇幅下限为原文 1/3，上限不设 1/2 硬顶，但提炼动作（压缩/抽取/砍冗余）不可省略，不是逐段照搬原文**
- 读起来应像「有人帮你读完并划了重点」
- 提炼后正文不得低于原文 1/3；篇幅超过 1/2 不视为未提炼，但逐段照搬原文视为未提炼

## 完整示例

```json
{
  "title": "王煜全：2029 年，AI 赛道泡沫破裂",
  "subtitle": "易论AI 深度对话 · 2026.07.09",
  "author": "张伟",
  "digest": "技术史 × 投资视角下的 AI 终局推演：泡沫时间表、电力之争、服务平权与人的去向",
  "content_type": "思辨/哲学",
  "source": "易论AI《王煜全：2029 年，AI 赛道泡沫破裂》深度访谈 · 2026.07.09",
  "blocks": [
    { "type": "intro", "text": "王煜全给这轮 AI 热定了一张时间表：2028 年形成巨大的「郁金香花球」，2029 年泡沫破裂……" },
    { "type": "highlight", "text": "发家致富的模式，从赚富人一个亿，变成从一亿人身上各赚一块钱。" },
    { "type": "divider" },
    { "type": "section", "title": "一、2029 年泡沫会破，破完是二十年繁荣", "body": "历史押韵不重复……\n\n现在的位置：低谷与狂热之间，在酝酿。" },
    { "type": "divider" },
    { "type": "endmark", "text": "∎" }
  ]
}
```
