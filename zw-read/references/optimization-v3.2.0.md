# zw-read v3.2.0 — 双角色交叉优化

**日期：** 2026-06-06
**方法：** Skill设计大师（SDM）+ 高效学习大师（ELM）双角色圆桌交叉审查
**产出：** 12项优化全部落地，版本升至 v3.2.0（350→437行）

## 12项优化速览

### P0（高影响·低成本）
1. **博彩翻顺序** — 先翻阅10分钟→写一句话锚定→再AI提取。修补锚定效应：AI先提取会过滤用户的原始认知
2. **翻阅不可跳过** — "5分钟看前言+目录"是最低门槛，不可跳过。保住了"接触过原文"的底线

### P1（中影响·中成本）
3. **先校准再自评** — 2b校准（AI先出检测）→ 2c自评（基于校准结果）。修补元认知盲区：越不懂的人越不自知，校准在前产生认知冲突，自评准确度大幅提升
4. **60秒空白检索（L0）** — 验证前第一步：合上书，60秒写下还能想起的所有东西。检索练习实证提升20-30%长期保留率
5. **阅读状态持久化** — Phase 6同步写入`.reading-state/{书名slug}.state`，支持跨session"继续读"恢复

### P2
6. **书面Feynman（L1）** — 3分钟口头→500字书面，降低门槛（不用找听众），AI做文字评审
7. **三级回访** — 单次30天→3天（短期巩固）+ 10天（中期检索）+ 30天（长期整合），间隔重复
8. **跨书连接** — Phase 3b增加跨书链接提问，笔记末尾自动生成`[[相关链接]]`

### P3
9. **情绪标签** — 章末摘要增加情绪触点标记（愤怒/兴奋/共鸣/困惑），杏仁核调节记忆编码
10. **内容挖掘意图** — Phase 1d增加"这本书有什么可做素材的"问题，视角从"普通人"锐化为"特定受众"
11. **缺口规格化** — 三种缺口：矛盾缺口/应用缺口/连接缺口。最多1个/份，留2个必须不同类型
12. **反馈闭环** — 每次读完一章或提取完成，AI问体验评分，记录随状态文件归档

## 关键认知科学原理注入

- **锚定效应（Kahneman）** — 博彩翻顺序的依据
- **邓宁-克鲁格效应 / 元认知盲区** — 校准先于自评的依据
- **检索练习效应（Roediger & Karpicke）** — L0空白检索的依据
- **艾宾浩斯遗忘曲线 + 间隔重复** — 三级回访的依据
- **杏仁核-海马体调节（情绪增强记忆）** — 情绪标签的依据
